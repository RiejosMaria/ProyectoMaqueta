Preguntas Frecuentes

Encuentra respuestas a las dudas más comunes sobre HTML y CSS.

¿Qué es CSS Grid y cuándo usarlo?

CSS Grid es un sistema de maquetación bidimensional que permite controlar filas y columnas al mismo tiempo. Es ideal cuando necesitas estructuras complejas como layouts de página, bento grids o cualquier diseño donde los elementos deben alinearse en dos ejes.

Usa Grid cuando el diseño dicta la estructura; usa Flexbox cuando el contenido la dicta.

¿Cómo funcionan las CSS Custom Properties?

Las Custom Properties (variables CSS) se declaran con el prefijo -- dentro de un selector, habitualmente :root, y se consumen con la función var(). Son en cascada como cualquier otra propiedad y se pueden sobreescribir en selectores hijos.

:root { --color-primary: #4338ca; }
button { background: var(--color-primary); }
¿Qué diferencia hay entre em y rem?

em es relativo al font-size del elemento padre más cercano. Esto puede acumularse si hay varios niveles de anidamiento, generando resultados inesperados.

rem (root em) siempre es relativo al font-size del elemento raíz (<html>), lo que lo hace mucho más predecible y es la unidad recomendada para espaciados y tipografía.

¿Qué son los elementos semánticos de HTML5?

Son etiquetas que describen el significado del contenido que encierran, no solo su apariencia. Ejemplos: <header>, <nav>, <main>, <article>, <section>, <aside> y <footer>.

Beneficios clave: mejoran la accesibilidad (lectores de pantalla), favorecen el SEO y hacen el código más legible y mantenible.

¿Cómo crear animaciones sin JavaScript?

CSS ofrece dos mecanismos principales: Transitions, para animar cambios de estado (hover, focus…), y Animations con @keyframes, para animaciones continuas o más complejas.

Para interactividad sin JS puedes combinar :checked en inputs ocultos con el selector ~ (hermano general) o + (hermano adyacente), como se hace en los tabs y el carrusel de esta misma página.
